# Weldcore Nordic AS

Flersidig industriell nettside for **Weldcore Nordic AS** – optimalisert for mobil, nettbrett/pad, PC/laptop og TV/4K-storskjermer, og publisert på Firebase Hosting (`https://weldcore.web.app`).

## Undersider
- `/` – Forside
- `/tjenester` – Tjenester innen sveising, stål og mekanisk arbeid
- `/prosjekter` – Leveranseområder og kvalitetssikring
- `/om-oss` – Om Weldcore Nordic AS
- `/kontakt` – Kontakt og forespørsel

## Kommandoer
- `npm run dev` – Start lokal utviklingsserver (`http://localhost:4817`)
- `npm run build` – Generer alle 5 sider til rot og `dist/`
- `npm run deploy` – Bygg og publiser til Firebase Hosting (`site: "weldcore"`)
